Chip's Challenge Native Remake — Release 1.0.1

Available package:
- windows/ — Windows x64 portable package
- macos/ — macOS ARM64, x86_64, and universal app ZIPs
- linux/ — Ubuntu 24.04 Linux x86_64 portable tar.gz

Packages include the offline HTML help manual and bundled Noto Sans. The Linux package was built and CTest-validated in Ubuntu 24.04 Docker. Linux background MIDI uses FluidSynth; the host needs `libfluidsynth3` and a General MIDI soundfont such as `fluid-soundfont-gm`, or set `FLUIDSYNTH_SOUNDFONT` to an SF2/SF3 file. Audible playback requires a working Linux audio device.
