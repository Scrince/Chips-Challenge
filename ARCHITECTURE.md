## Deterministic replay support

`src/replay.hpp` exposes an SDL-independent replay script made from queued moves, immediate physical input events, mouse targets, and explicit tick advances. A script includes the campaign level number, initial random seed, and initial global tick phase; `runReplay` rejects mismatched level identity and returns a compact snapshot after every command. Each snapshot includes a stable 64-bit digest covering both live map layers, inventory, moving blocks, creatures, links, slip ordering, timers, random state, pending input, and outcome, alongside a few fields useful in test failure output. The regression suite runs the same seeded Blob scenario twice and compares each state digest. Replays start from a decoded level's initial board state with explicit tick/RNG phases; arbitrary mid-level saves are not supported by this format yet. The original increments `CurrentTick` globally and calls `srand` once at application startup, so native campaign level transitions and restarts now preserve both phases while resetting level-local gameplay state.

## Recent source comparison

When Chip pushes a block, the block's old square becomes Chip's tile and its lower layer resets to floor before the old upper tile's entry action is applied. The engine now clears pickups from that square instead of leaving a collectible beneath Chip to be collected repeatedly; a regression covers a blue key beneath a block.

The exit rule is intentionally not a chip-counter gate. The source `ChipCanEnterTile` table marks Exit enterable for Chip with action 4, and the subsequent `MoveChip` path completes when the resulting lower layer is Exit.
