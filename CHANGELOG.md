# Chips Challenge — V1.0.1

## Changes

- Refined the in-game interface with Noto Sans typography, clearer spacing, and updated menu branding.
- Added the original menu background artwork behind the game and menu screens.
- Updated the classic Game, Options, Level, and Help menus.
- Added an offline HTML help manual containing the original WinHelp topics and illustrations; Help menu entries and F1 open the matching topic without requiring a `.HLP` viewer.
- Reworked Go To Level to use centered fields limited to 10 characters and accept either a level/password pair or a password alone; the main-menu Enter Password action opens this dialog, replacing the separate password panel.
- Fixed the thief sound so it plays whenever Chip enters a thief tile, including when the thief steals equipped boots.
- Improved the level picker with a selected-level summary, status legend, map preview, and close button.
- Added top-right close buttons to in-game dialogs and overlays.
- Fixed menu pointer alignment and removed the main-menu keyboard hint line.
